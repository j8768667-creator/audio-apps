How it works: the engine fingerprints the final bars using onset density, pitch classes, velocity and harmony, then searches a wider recent history for plausible musical successors. Rhythmic/harmonic source material is kept synchronized across tracks while melodic tracks receive key-aware interval variation and chordal tracks receive conservative voicing variation. End-of-track padding is ignored so the continuation begins at the final sounding note. The browser preview uses simple synths; the exported file retains MIDI note, program, controller and pitch-bend data.
